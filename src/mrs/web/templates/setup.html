🎧 Music Request

Ask Siri for a song and it plays on this PC.

Your endpoint
http://{{ host }}:{{ port }}/?key={{ api_key }}

Build the Shortcut on your iPhone

  1. Open Shortcuts → + → Add Action.
  2. Add Dictate Text.
  3. Add Get Contents of URL and paste the endpoint above.
  4. Set Method to POST, Request Body to JSON.
  5. Add one field: key input, type Text, value = Dictated Text.
  6. Name it something you'd say out loud, like “Play music”.

Then: “Hey Siri, Play music” → “play something by Fleetwood Mac”.

Skip the dictation

For a one-phrase shortcut, drop the Dictate step and put the words straight into input — “Hey Siri, evening jazz”.

If nothing plays

YouTube needs a logged-in session. Open the player, go to Settings → Find cookies, and follow what it tells you.
