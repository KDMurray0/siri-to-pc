🎧 Music Request

This isn't a web page — it's the endpoint your iPhone talks to. Build a one-tap Siri Shortcut and just say what you want to hear.

Your endpoint
http://{{ host }}:{{ port }}/?key={{ api_key }}

Keep this key private — anyone on your network with it can control playback.

Build the Shortcut
  1. Open Shortcuts → + to create a new one. Name it something Siri hears clearly, like Play Music.
  2. Add Ask for Text — prompt: "What would you like?"
  3. Add Get Contents of URL:
    • URL: the endpoint above
    • Method: POST
    • Request Body: JSON
    • Field: input = Dictated Text (the Ask-for-Text result)
  4. Add Get Dictionary Value — key message.
  5. Add Speak Text (or Show Notification) with that value, so Siri reads back what's playing.

Then just say "Hey Siri, Play Music" and speak a song, artist, or vibe — "play some punk", "coming undone by korn", "turn it up", "more like this", "surprise me".

Optional setup
  1. Smarter understanding (recommended) — add a free Groq key so requests are understood by an AI (knows "queen" is a band, "punk" is a genre). In config.json set "groq_api_key" to your key. On by default once a key is present.
  2. Start on boot (off by default) — opt in from the music player's Settings (gear icon) → Start on boot. It then launches hidden to the tray when you sign in.
  3. Announce & more — the same Settings sheet has spoken now-playing, crossfade, EQ, volume normalize, sleep timer, and a "Lock to my devices" toggle (off = any device on your Wi-Fi).

Your settings live in %LOCALAPPDATA%\MusicRequestServer\config.json and persist across updates.
